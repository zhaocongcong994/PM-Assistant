# 产品拆解示例

## OiiOii · 剧本和角色设计

随包示例选自 OiiOii 案例中的创意输入、剧本确认和角色图片确认截图。

1. 在浏览器打开 [用户旅程参考报告](oiioii/index.html)，点击条目中的证据编号查看截图。
2. 在 Nexus 的「产品拆解」中输入产品名 `OiiOii`，选一个支持图片输入的模型。
3. 按 [图片清单](oiioii/图片清单.csv) 的顺序上传 [S01](oiioii/screenshots/S01.png)、[S02](oiioii/screenshots/S02.png)、[S03](oiioii/screenshots/S03.png)，点击「开始拆解」。
4. 核对旅程和证据编号，点击「确认旅程并继续」。完成后下载报告，解压并打开 `index.html` 查看汇总。

样例覆盖主流程的前三个阶段。可用参考报告检查事实和推断的粒度，模型生成的文字会随模型和配置变化。
